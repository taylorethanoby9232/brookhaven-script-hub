## About the Script

Brookhaven RP Script adds a small set of convenience tools to the Roblox Brookhaven roleplay experience. Its main functions remove stamina restrictions for longer periods of movement and provide aiming support when an activity calls for more accurate targeting. By reducing repetitive gameplay actions, the utility leaves more room for roleplay and exploration.

Version 1.0 is intended to remain responsive and stable with the current Brookhaven RP release. It runs as a lightweight overlay and connects with relevant game events to provide consistent behavior. The utilities can be used while traveling around the city, taking part in pursuits, or joining community activities.
